# Michael Bush IT Portfolio Website

This starter portfolio includes:

- index.html
- styles.css

## How to use

1. Open `index.html` in a browser to preview it.
2. Edit the text in `index.html` to match your exact experience.
3. Replace contact info, LinkedIn, and any project details as needed.
4. Upload both files to GitHub Pages, Netlify, Cloudflare Pages, or your web host.

## Public safety note

Before publishing, remove or sanitize:
- Company name
- Public IP addresses
- Internal IP schemes
- Real firewall rules
- Passwords or usernames
- Screenshots with sensitive details
- Internal diagrams that reveal security design
